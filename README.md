# paprika_artstudio
First Claude Test Project

Сайт інклюзивної творчої студії Paprika Artstudio.

## Майстер-класи: як оновлювати

Тексти майстер-класів лежать у `data/masterclasses.json`, а фото — у папках `images/masterclasses/<slug>/`.
Сторінки `masterclasses.html`, `masterclasses/*.html` і блок «Майстер-класи» на головній створює скрипт, тож **вручну їх не редагуйте**: зміни зітруться під час наступного запуску.

Після будь-якої зміни запустіть скрипт. У VS Code відкрийте меню «Терминал → Создать терминал» і введіть:

```
node tools/build-masterclasses.js
```

### Додати фото

1. Покладіть фото в папку потрібного майстер-класу, наприклад `images/masterclasses/ebru/`.
2. Назвіть файли `1.jpg`, `2.jpg`, `3.jpg`… Фото `1.jpg` — обкладинка.
3. Запустіть скрипт. Він сам зменшить завеликі фото й зробить мініатюри в папці `thumbs/`.

Підходять JPG і PNG. Фото з iPhone у форматі HEIC спершу збережіть як JPG.
Щоб читач екрана описував фото змістовно, додайте опис у поле `alts` майстер-класу, наприклад `"alts": { "2.jpg": "Діти розписують шопери" }`.

### Додати відео

Завантажте відео на YouTube (або візьміть посилання з Instagram) і впишіть його в поле `videos`:

```json
"videos": [{ "url": "https://youtu.be/XXXXXXXXXXX", "duration": "2:15" }]
```

### Додати новий майстер-клас

Скопіюйте в `data/masterclasses.json` блок будь-якого майстер-класу, змініть `slug` (латиницею, через дефіс), назву й тексти, а потім запустіть скрипт.
Папку для фото скрипт створить сам.
